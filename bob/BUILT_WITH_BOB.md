# Built with IBM Bob

This project was developed with assistance from **IBM Bob** — IBM's AI-powered shell assistant for developers.

## How IBM Bob Was Used

| Feature | Bob's Role |
|---|---|
| **XGBoost model implementation** | Bob helped generate the model training pipeline, feature engineering, and evaluation code |
| **FastAPI backend structure** | Bob assisted in scaffolding the API endpoints and middleware configuration |
| **granite.py — Granite integration** | Bob helped implement the dual-provider AI client (watsonx.ai + HuggingFace) |
| **Frontend TypeScript components** | Bob generated React component templates, state management patterns, and API client code |
| **CSS styling (dark theme)** | Bob provided design tokens and responsive layout patterns |
| **README and documentation** | Bob helped structure the project documentation |
| **Bug fixes and refactoring** | Bob assisted in debugging import errors, API response handling, and TypeScript type issues |

## IBM Bob CLI Commands Used

Throughout development, Bob was invoked with prompts such as:

```
# Initial project scaffolding
bob "create a FastAPI backend for a football match prediction system"

# AI integration 
bob "add IBM Granite integration with watsonx.ai and HuggingFace fallback"

# Frontend development
bob "create a React component for match prediction with team selection"

# Debugging
bob "fix CORS error in FastAPI backend"

# Documentation
bob "write a project README for the IBM AI Builders Challenge"
```

## Why IBM Bob?

IBM Bob accelerated development by handling boilerplate code, suggesting best practices, and debugging issues in real time — allowing me to focus on the core AI/ML logic and user experience rather than infrastructure plumbing.
